# Jash Files

An iOS-style file manager for Android.

## ⬇️ Download

**[Download the latest Jash Files APK](https://github.com/shahadmangaden/JashFiles/releases/latest/download/JashFiles.apk)**

Open the downloaded file on your phone to install it, and allow "Install unknown apps" if asked.

## Features

- iOS-style home page with storage rings, categories and tools
- Browse internal storage and SD card, with search, sorting, and list or icon view
- Copy, move, rename, duplicate, share, delete and get info
- ZIP compress and extract
- Recycle Bin with restore
- Encrypted folder (AES-256, password protected)
- Cleanup and Auto Cleanup
- View on PC: browse, download and upload over Wi-Fi from any browser
- FTP, LAN (SMB) and WebDAV servers
- Send via Bluetooth
- Light and dark mode

## How it's built

`JashFiles.zip` contains the full Android Studio project (Kotlin and Jetpack Compose).
Every time it changes, GitHub Actions builds the app and updates the download link above.
